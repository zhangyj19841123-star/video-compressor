视频压缩转换器 · Windows 版
========================================

适用系统：Windows 7 / 8 / 8.1 / 10 / 11，64 位
无需安装：不依赖 .NET 额外版本、VC++ 运行库、UCRT 或任何驱动
硬件要求：任意 x64 CPU，不要求 AVX / 独立显卡 / 硬件编码

【开始使用】
双击 START.bat（或「视频压缩转换器.bat」）打开窗口。
把一个或多个视频拖进窗口任意位置，松手即自动开始压缩，不需要再点按钮。
也可以点窗口中间的虚线框选择文件。

【保底方式】
如果图形界面被公司安全策略拦截，把视频直接拖到
「Drag videos onto me.bat」上，效果完全一样（命令行窗口显示进度）。

【输出】
默认保存到「视频 > 视频压缩输出」，界面上可更改。
文件名：原名_压缩版.mp4（保底脚本为 _compressed.mp4）。
同名自动加序号，原文件不会被修改或删除。

【画质与帧率】
默认 HEVC CRF 16（视觉无损档）；录屏实测体积约缩到 1/4，SSIM 约 0.999。
界面可切换 CRF 16/18/20/22、HEVC / H.264、是否保留音轨、是否做 SSIM 画质校验。
不缩放、不改色彩、不改分辨率；音轨默认直接复制，不二次编码。
输出强制恒定帧率（CFR）并固定 MP4 时间基，避免剪辑软件里音画不同步。

【关于 HEVC 兼容性】
Win10/11 自带播放器可直接播 HEVC；Win7/8 自带播放器不支持，
建议用 VLC / PotPlayer，或在界面改选「H.264 · 老设备兼容」。

许可证与构建说明见 bin\LICENSE 与 bin\README.txt。

【关于文件名】
为避免不同语言版 Windows 解压出现乱码，主启动器用英文名 START.bat；
中文名「视频压缩转换器.bat」是同一个程序的别名，双击任意一个都可以。
本说明使用 UTF-8 BOM + CRLF，Windows 7 自带记事本可直接正常显示。
